NOAVUS VOTE – iPhone Web-App

Diese Variante braucht keinen Mac und keinen App Store.

So benutzt du sie:
1. Lade den Ordner auf einen Webspace oder statischen Hoster mit HTTPS.
2. Öffne die Seite auf dem iPhone in Safari.
3. Tippe auf Teilen.
4. Wähle „Zum Home-Bildschirm“.
5. Danach startet Noavus Vote wie eine kleine App im Vollbild.

Vote-Links:
https://minecraft-server.eu/vote/index/208F7/Noavus
https://www.minecraft-serverlist.net/vote/51076/Noavus

Hinweis:
iOS lässt das automatische Öffnen von zwei externen Seiten mit nur einem Tap nicht immer zuverlässig zu.
Darum gibt es zwei große Vote-Buttons.
